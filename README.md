# Deteccao-de-objetos-no-Android
Aplicativo desenvolvido em Android Nativo e Kotlin com XML com o objetivo de treinar a eficacia de um modelo de IA de detecção de objetos desenvolvido por mim, atraves da camera de um celular android.
Foi utilizado a biblioteca YOLOV8 para o treinamento do modelo em Python e Tensorflow para o processamento da imagem no app android.
